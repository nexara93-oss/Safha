# Security S06 — Webhooks & Email Flows

## Mission
Email verification and webhook flows. Find bypasses.

## Checklist
1. Verification token reuse
2. Token doesn't expire
3. Token not invalidated after use
4. Email enumeration (response diff on existing vs missing user)
5. Resend spam
6. Predictable token (not enough entropy)
7. Token in URL leaks via referrer
8. SMTP relay open
9. Email injection (BCC headers)
10. DKIM/SPF/DMARC recommended

- Exploit demos
- Patches
