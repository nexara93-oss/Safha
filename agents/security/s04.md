# Security S04 — Secrets & Configuration

## Mission
Find leaked secrets and weak configuration. Fix them.

## Checklist
1. `.env` committed
2. `.env.example` contains real secrets
3. `JWT_SECRET` hardcoded fallback
4. DB credentials in client bundles
5. Gmail app password in client
6. Debug logs leaking tokens
7. Source maps expose server code
8. Admin seed in client code
9. Stripe/webhook secrets exposed
10. Production secrets ≠ dev secrets

## Deliverables
- Fixes
