# Security S09 — Messaging & Realtime Abuse

## Mission
Spam, impersonate, leak. Fix the chat system.

## Checklist
1. Send to invalid user ID
2. Send huge messages (DoS)
3. Send HTML / script in messages
4. Read other users' messages
5. Mark someone else's message as read
6. Pollute conversation list
7. ChatApp polling endpoint cost
8. Self-message loop
9. Group message leaks (TEACHER → wrong STUDENT)
10. Broadcast recipient count leak
