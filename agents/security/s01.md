# Security S01 — Authentication & Sessions

## Mission
Find broken authentication. Exploit weaknesses. Fix them.

## Checklist
1. JWT secret strength (`JWT_SECRET` ≥ 32 bytes random)
2. Token expiry — long-lived tokens dangerous
3. Cookie flags: `HttpOnly`, `Secure`, `SameSite`
4. Password hashing (bcrypt vs plaintext)
5. Password reset flow token reuse
6. Brute-force protection (rate limiting on `/api/auth/login`)
7. Session fixation
8. Logout invalidates server-side
9. CSRF tokens on POST
10. Email verification bypass attempts
