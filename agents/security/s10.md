# Security S10 — Mobile / Capacitor Build

## Mission
The Android APK ships the same code. Audit it.

## Checklist
1. `capacitor.config.ts` server URL exposed
2. Deep links open arbitrary URLs
3. Cleartext traffic allowed (`usesCleartextTraffic`)
4. Backup allowed (`android:allowBackup`)
5. Permissions over-requested (`READ_CONTACTS`, etc.)
6. WebView JavaScript interface enabled
7. Hardcoded API keys in APK
8. ProGuard / R8 minification
9. `android:exported` for activities
10. WebView file access

## Deliverables
- Config fixes
- `agents/findings/s10.json`
