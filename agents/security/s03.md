# Security S03 — API Abuse & Rate Limiting

## Mission
Try to abuse the API: spam endpoints, scrape data, bypass quotas. Add protections.

## Checklist
1. No rate limiting on `/api/auth/login` (brute force)
2. No rate limiting on `/api/messages` (spam)
3. No rate limiting on password reset
4. No rate limiting on email verification resend
5. Bulk export endpoints (teachers list, students list)
6. Pagination missing — return all rows
7. Cost amplification (one request → many DB queries)
8. Memory exhaustion (huge JSON payload)
9. Slowloris / large body
10. Missing `Content-Length` cap

## Deliverables
- Exploit demos
- Rate limit middleware
- `agents/findings/s03.json`
