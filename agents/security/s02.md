# Security S02 — Input Injection (XSS, SQLi, Command)

## Mission
Inject malicious payloads into every input. Find sinks. Fix them.

## Checklist
1. Reflected XSS in error messages
2. Stored XSS via `fullName`, message content, lesson description
3. `dangerouslySetInnerHTML` anywhere
4. SQLi via Prisma raw queries (`$queryRaw`)
5. NoSQLi (N/A — using Postgres)
6. Command injection (none expected — no `exec`)
7. Path traversal in file URLs (lessons, homework)
8. Header injection (HTTP headers from user input)
9. LDAP injection (N/A)
10. Open redirect in post-login redirect

## Deliverables
- Exploit demos
- Patches (sanitize / escape)
- `agents/findings/s02.json`
