# Security S07 — Data Exposure

## Mission
Find data leaking where it shouldn't. Fix.

## Checklist
1. Password hash returned by API
2. Email exposed in list endpoints
3. Phone exposed (PII)
4. `generatedPassword` returned to anyone
5. Subscription `endDate` exposed unnecessarily
6. Internal IDs leak structure
7. Error messages reveal DB schema
8. Stack traces in production
9. Verbose 500s
10. `Access-Control-Allow-Origin: *` on auth endpoints

## Deliverables
- Patches (narrow `select`)
- `agents/findings/s07.json`
