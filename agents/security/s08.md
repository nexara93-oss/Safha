# Security S08 — Subscription & Payment Edge Cases

## Mission
Try to game the subscription / payment system. Fix loopholes.

## Checklist
1. Replay a completed payment
2. Cancel a payment then keep subscription
3. Downgrade plan without paying difference
4. Extend trial by re-registering
5. Negative amount payment
6. Zero amount
7. Currency manipulation (USD vs MAD)
8. Coupon / promo bypass
9. Webhook signature bypass
10. Race condition: extend subscription concurrently

- Exploit demos
