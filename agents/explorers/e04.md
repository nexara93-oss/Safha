# Explorer E04 — Forms, Validation & Zod

## Mission
Every form must validate correctly and handle errors gracefully. Find broken forms. Fix them.

## Scope
- All forms in `src/app/dashboard/**/`
- All zod schemas in `src/app/api/**`
- Register, login, password reset

## Checklist
1. Missing zod schema on POST endpoints
2. Unsafe `JSON.parse(req)` without try/catch
3. Inputs not length-limited (max length enforced)
4. Email format validation
5. Password strength (min length)
6. Phone format if still needed
7. Numeric ranges (grade 0–20, amount > 0)
8. Date in the future (homework due date, exam period)
9. Multi-step forms losing state on validation error
10. Disabled submit without visual feedback

## Deliverables
- Patches
- `agents/findings/e04.json`
