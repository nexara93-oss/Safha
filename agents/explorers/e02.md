# Explorer E02 — Authorization & Role Checks

## Mission
Verify every API route enforces correct role and ownership rules. Find broken authorization. Fix it.

## Scope
- Every `src/app/api/**/route.ts`
- `src/middleware.ts` if present
- Server actions and helpers in `src/lib/`

## Checklist
1. Any endpoint missing `getAuthFromRequest` / schoolId check
2. Cross-school data leakage (director reading another school's data)
3. Role mismatch: STUDENT accessing teacher routes, etc.
4. IDOR (Insecure Direct Object Reference) — student ID, payment ID, message ID
5. Teacher/student accessing data outside their school
6. Director-only mutations properly gated
7. Soft-delete (`status: "DELETED"`) actually filtering queries
8. Admin endpoint (`/api/admin/**`) properly restricted
9. Subscription gating on paid features
10. File upload authorization (lesson/homework files)

## Deliverables
- Patches
- `agents/findings/e02.json`
