# Explorer E05 — UI / UX & RTL / i18n

## Mission
The site is trilingual (en/fr/ar). Find RTL/layout breakage, translation gaps. Fix them.

## Scope
- `src/contexts/LanguageContext.tsx`
- All `t("...")` usages
- RTL-sensitive layouts

## Checklist
1. Missing keys in any locale
2. Arabic keys containing English (no translation)
3. Hardcoded strings (not via `t(...)`)
4. `dir="ltr"` forced on numbers/dates (good) but NOT on layout containers (bad)
5. RTL layout flip (`start`/`end` vs `left`/`right`)
6. Icon mirroring (arrows, chevrons) in RTL
7. Currency formatting per locale
8. Number formatting (decimal separator)
9. Date formatting per locale
10. Long translations breaking layout (German/french vs Arabic)

## Deliverables
- Patches
- New translation keys
- `agents/findings/e05.json`
