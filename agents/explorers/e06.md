# Explorer E06 — Error Handling & Logging

## Mission
Every API must fail safely. Find uncaught throws, leaking stack traces, missing error UI. Fix them.

## Scope
- All `route.ts` handlers
- Client-side error boundaries

## Checklist
1. Try/catch around all DB calls
2. Zod errors → 422 with field errors
3. Generic 500 messages (no stack traces leaked)
4. `err.message` not exposed to clients
5. Toast on every failed action
6. Loading state cleared in `finally`
7. Optimistic updates with rollback
8. Network timeout handling
9. Retry on transient errors (Postgres disconnect)
10. Empty-state error UI ("Failed to load. Retry?")
