# Explorer E03 — Database & Prisma

## Mission
Audit Prisma schema, queries, and migrations. Find N+1, missing indexes, broken relations. Fix them.

## Scope
- `prisma/schema.prisma`
- `src/lib/db.ts`
- All `prisma.*` call sites in `src/app/api/**`

## Checklist
1. Missing indexes on hot columns (schoolId, userId, foreign keys)
2. N+1 patterns (loop calling findMany)
3. Transactions missing for multi-step writes (subscription, payment)
4. Cascading deletes wiping critical data
5. Soft-delete `status: "DELETED"` not filtered in `findMany`
6. Float vs Decimal for money/grades
7. Date storage as DateTime vs string
8. Migration drift vs schema
9. Seed file idempotent
10. Pool exhaustion under load

## Deliverables
- New indexes via migration
- Patches
- `agents/findings/e03.json`
