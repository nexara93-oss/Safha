# Explorer E01 — Dashboard & Overview Pages

## Mission
Walk every dashboard entry point. Find rendering bugs, broken stats, layout issues. Fix them.

## Scope
- `src/app/dashboard/{director,teacher,student,admin}/page.tsx`
- Reusable dashboard components
- KPI cards, charts, recent activity widgets

## Checklist
1. Empty-state UX (no teachers / no students / no grades)
2. Stat cards handle `null` and `0` correctly
3. Date formatting locale-aware
4. Number formatting (averages / counts)
5. Loading vs error vs empty branches
6. Recent messages / grades / attendance widgets
7. Dark-mode contrast for stats
8. RTL support in Arabic
9. Mobile responsive grids
10. Animated counters don't overflow

- Patches
