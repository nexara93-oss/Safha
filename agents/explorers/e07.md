# Explorer E07 — Performance & Caching

## Mission
Make the app fast. Find slow queries, missing cache, unthrottled polling. Fix them.

## Scope
- Server queries
- Client polling / setInterval
- Static vs dynamic rendering

## Checklist
1. `cache: "no-store"` everywhere (over-fetches)
2. `revalidate` / `Cache-Control` headers
3. `Promise.all` instead of sequential awaits
4. select narrow payloads (`select` in prisma)
5. Pagination / `take` limits
6. Client polling rate (ChatApp polls every 8s — sane?)
7. Heavy computation on render
8. Image optimization (next/image)
9. Bundle size (Lucide icons: import one-by-one ✓)
10. Lighthouse targets
