# Explorer E08 — Accessibility (a11y)

## Mission
Find accessibility violations. Fix them.

## Scope
- All interactive components
- Forms, modals, dropdowns, navigation

## Checklist
1. Buttons without `aria-label` (icon-only)
2. Form inputs without `<label>`
3. Missing focus states
4. Tab order issues
5. `role="..."` missing on custom widgets
6. Color contrast (WCAG AA)
7. Keyboard navigation broken
8. Screen reader-only text missing
9. Modals trap focus incorrectly
10. Live regions for toasts/notifications

## Deliverables
- Patches
- `agents/findings/e08.json`
